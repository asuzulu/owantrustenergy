# Owan Trust Energy App

## Description
Owan Trust Energy is a web application built with Laravel that provides users with functionality for registration, sign-in, and password management. The app features a responsive design, allowing users to access it seamlessly on various devices. 

## Features
- User registration with validation
- Secure sign-in with password protection
- Password reset functionality
- State selection for user registration
- Responsive design for mobile and desktop

## Technologies Used
- PHP 8.3.13
- Laravel 11.28.1
- HTML/CSS/JavaScript
- Bootstrap for responsive design
